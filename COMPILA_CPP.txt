COMPILAZIONE DLL Q8_0 -> BF16 DEQUANTIZER
=========================================

REQUISITI:
- Visual Studio 2022 (già installato)
- Componenti C++ (Desktop development with C++)


METODO 1: Da Developer Command Prompt (consigliato)
-------------------------------------------------------
1. Apri: "Start Menu" -> "Developer Command Prompt for VS 2022"

2. Vai nella cartella del progetto:
   cd C:\Users\valer\Desktop\moe-client-prot\Nuova cartella

3. Compila la DLL:
   cl /EHsc /O2 /arch:AVX2 /openmp /LD scratch\fast_dequant_q8_0.cpp /link /OUT:flash_moe\fast_dequant_q8_0.dll /DLL /MACHINE:x64

4. Verifica che il file esista:
   dir flash_moe\fast_dequant_q8_0.dll


METODO 2: Da PowerShell
------------------------
1. Apri PowerShell

2. Esegui:
   $env:VCINSTALLDIR = "C:\Program Files\Microsoft Visual Studio\2022\Community\VC\"
   Import-Module "$env:VCINSTALLDIR\Auxiliary\Build\Microsoft.VCTools.Install.psd1"
   Initialize-VCTools

3. Poi compila come nel Metodo 1


METODO 3: Esegui il batch file
------------------------------
Doppio click su: compile_dequant_q8_0.bat


OPZIONI DI COMPILAZIONE:
- /EHsc   : Exception handling
- /O2     : Ottimizzazione massima
- /arch:AVX2 : Abilita AVX2
- /openmp : Abilita OpenMP (per parallelismo)
- /LD     : Crea DLL
- /Zi     : Debug info (opzionale, può essere rimosso)


FLAG AGGIUNTIVE PER OTTIMIZZAZIONE:
- /O2 /GL : Link-time code generation
- /Qpar   : Auto-parallelizzazione
- /Qvec   : Auto-vettorizzazione

Comando ottimizzato:
cl /EHsc /O2 /GL /arch:AVX2 /openmp /LD /Qpar /Qvec scratch\fast_dequant_q8_0.cpp /link /OUT:flash_moe\fast_dequant_q8_0.dll /DLL /MACHINE:x64 /LTCG


NOTE:
- Il file C++ è in: scratch\fast_dequant_q8_0.cpp
- L'output DLL va in: flash_moe\fast_dequant_q8_0.dll
- Lo script Python si aspetta la DLL in: flash_moe\fast_dequant_q8_0.dll
